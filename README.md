`리액트 훅을 활용한 마이크로 상태관리`에 큰 인사이트를 얻고, 커스텀 훅을 사용하기 시작했습니다. <br />
그러나 과연 커스텀 훅을 이렇게 항상 분리 하는 것이 정답일까?<br /> 
괜히 함수를 분리하여, 개발 경험 저하만 불러오지 않을까 하는 고민을 하게 되었습니다. <br />
<br />
그 뒤로 리액트 디자인 패턴, 함수형 프로그래밍, 객체 지향등을 공부하면서, <br />
컴포넌트를 함수로 바라보는 관점과, `createElement()`의 결과값을 고려하면서 리액트 컴포넌트에 접근해야한다는 것을 배웠습니다.<br />
즉 커스텀 훅을 만들더라도, 이 상태와 관련된 jsx문을 분리하고 children 혹은 커스텀 컴포넌트 생성함으로써 불필요한 리렌더링을 방지해야합니다.<br />
